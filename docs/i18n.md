# i18n — 国际化说明

The port embeds two message catalogs (English and Chinese) in `src/i18n.rs`.
No runtime dependency (no gettext) — strings are compiled in.

## Message resolution order

1. `--lang en` / `--lang zh` — the flag is pre-scanned and stripped from argv
   before the faithful argument parser runs, so it works anywhere on the
   command line without changing any original flag semantics. An invalid
   value is a fatal error (`invalid language: <v> (expected: en, zh)`).
2. `LC_ALL` → `LC_MESSAGES` → `LANG` — the first non-empty variable wins;
   a locale whose first two characters are `zh` selects Chinese, anything
   else English.
3. English (default).

## Translation scope

- **Translated** (sentence-like): usage text, argument errors
  (`invalid source IP address`, `Unknown arg`, `ID argument … not between 1
  and 99`, `Port argument not valid`, `You must be root …`), debug status
  lines (`ID set to …`, `found N interfaces total`, `Echo (Ignored)`,
  `Not from managed iface`, `Done Initializing`), perror prefixes
  (`Source IP not found on incoming packet` …).
- **Kept identical in every language** (identifiers / data-heavy log lines):
  syscall labels passed to perror (`socket`, `bind`, `sendto`,
  `ioctl(SIOCGIFINDEX)`, `setsockopt …`), per-interface data lines
  (`eth0: 2 / 10.0.0.5 / 10.0.0.255`), the `<- [` / `-> [` packet log lines,
  and `IP_ADD_MEMBERSHIP:\t\t…`.

This mirrors common practice (OS error strings and syscall names stay in the
OS language) and keeps the data lines grep-able across locales.

## Quirk preservation

The original embeds a trailing `\n` inside some perror prefixes (e.g.
`perror("Source IP not found on incoming packet\n")`), which makes the printed
error span two lines. The catalogs preserve this byte-for-byte in English.

## Adding a language

1. Add a variant to `pub enum Lang` and map a locale prefix in
   `Lang::from_locale` + `Lang::parse` (the `--lang` value).
2. Add one match arm returning the translated string to every message method
   in `impl I18n`.
3. Add a `USAGE_<LANG>_BODY` constant next to the English one and reference it
   from `usage()`.
4. Extend the `--lang` doc text in `invalid_lang` (the "expected:" list) and
   README / README.zh-CN.md tables.

Everything the user can see flows through `impl I18n` methods — there are no
hardcoded user-facing strings outside `src/i18n.rs` (modulo the perror labels
and data-line formats that are intentionally locale-independent).
